 Projeto prático de detecção e reconhecimento facial com prova de vida (liveness detection).

Neste vídeo demonstramos um sistema de segurança baseado em reconhecimento facial, que vai além da simples detecção de rostos. O sistema solicita ações como mexer a cabeça e sorrir, garantindo que o reconhecimento seja feito apenas com pessoas reais, evitando fraudes com fotos ou vídeos.

 Tecnologias utilizadas:

OpenCV

Python

Mediapipe

Face Recognition

Controle de acesso seguro
